💻🔬 Scientific Software & Digital Geoscience

My software projects cover desktop applications, web applications, scientific data processing, and geoscience workflow automation.

🔬 GeoHySpec

Hyperspectral Geoscience | Desktop Scientific Application

Portable desktop software for hyperspectral analysis and mineral characterization of geological samples. Currently used internally at KFUPM to process data collected with the HySpex SWIR-384 in laboratory and field settings.

Public release planned.

Role: Project Lead & Developer

📄 Software manuscript in preparation (2026)

🔬 Geothermie

Geothermal Energy | Scientific Web Application

geothermie.geovartha.id

Web application for geothermal subsurface analysis, integrating geoscientific datasets and analytical workflows into interactive tools. Public access is planned following publication of the associated manuscript.

Role: Project Lead & Developer

Scientific workflow: Published in Geothermics and demonstrated on a real-world case study (DOI).

📄 Software manuscript: In preparation (2026).

🔬 Wellcast

Well Data | Scientific Web Application

https://wellcast.geovartha.id/

Web application tool for predicting missing well log data using the machine learning workflow.

The project focuses on translating the SPEC GCS ML Challenge 2021 into a reproducible workflow.

Role: Project Lead & Developer

📄 Citable software/research output available: Wellcast

🔬 Spectral-Box

Spectral Geology | Scientific Web Application

https://spectral.geovartha.id/

Spectral Box is a web app for rapid spectral interpretation. Upload your spectral data, visualize it across VNIR-SWIR-MWIR-LWIR, apply continuum removal and normalization, then compare your sample against reference spectra and automatically find the closest matches from the libraries.

Role: Project Lead & Developer
